강화학습 모델을 통한 제네시스 2026 SPA FRANCORCHAMPS 전략 평가

**팀명:** 마그마마인드 (MagmaMind)

**분야:** 데이터 분석 / 강화학습 (RL)

##  프로젝트 개요
WEC 하이퍼카 클래스의 피트스탑은 레이스 결과를 가르는 핵심 요소입니다. 본 프로젝트는 과거 경기 데이터를 학습하여 피트스탑 전략이 최종 순위에 미치는 영향을 분석하고, AI 기반의 강화학습 모델을 통해 제네시스 마그마 레이싱팀을 위한 최적의 피트스탑 의사결정 보조 시스템을 구축하는 것을 목표로 합니다.

##  아키텍처: 2단계 AI 파이프라인
 **과거 데이터에서 정답을 유추하는 평가기와 최적의 행동을 찾는 결정기**로 이루어진 2단계 파이프라인을 활용합니다.

1. **Step 1. 전략 평가기 (XGBoost):**
   * 현재 주행 상태(`stint_lap`, 선두와의 시간 격차, 트랙 온도, 깃발 상태 등)를 바탕으로 포디움(3위 이내) 진입 확률을 0.0 ~ 1.0 사이로 예측합니다.
2. **Step 2. 의사결정 에이전트 (MaskablePPO):**
   * XGBoost의 확률 예측 변화량을 실시간 보상(Reward)으로 삼아, 매 랩마다 '계속 주행' 또는 '피트인' 여부를 결정합니다. 연료 고갈이나 의무 주행 규정 등은 **액션 마스킹(Action Masking)**을 통해 제어하여 학습 효율을 극대화합니다.
